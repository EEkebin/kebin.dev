AI CLI

Run a coding agent on your own machine, in your own project, using the models on ai.kebin.dev. Pick a tool, then your system.

API key

Already filled into the commands below, and the same for all three tools. Keep it private: anyone with it can use the GPU.

__AIBOX_KEY__

Install

Installs OpenCode 2, replacing OpenCode 1 if you have it, and writes the config with the key above: models, web search and page fetch.

curl -fsSL https://kebin.dev/cli/install.sh | AIBOX_KEY=__AIBOX_KEY__ bash

Then

Open a project folder and start it. Pick a model inside OpenCode with /models.

cd my-project
opencode

Uninstall

Removes the kebin.dev profile and restores your previous OpenCode config. The second form also removes OpenCode itself.

curl -fsSL https://kebin.dev/cli/uninstall.sh | bash
curl -fsSL https://kebin.dev/cli/uninstall.sh | bash -s -- --all

Install

PowerShell. Installs OpenCode 2, replacing OpenCode 1 if you have it, through npm if you have Node.js, otherwise as a standalone download. Writes the config with the key above: models, web search and page fetch.

$env:AIBOX_KEY = "__AIBOX_KEY__"; Invoke-RestMethod https://kebin.dev/cli/install.ps1 | Invoke-Expression

Then

Open a project folder and start it. Pick a model inside OpenCode with /models.

cd my-project
opencode

Uninstall

Removes the kebin.dev profile and restores your previous OpenCode config. The second form also removes OpenCode itself.

Invoke-RestMethod https://kebin.dev/cli/uninstall.ps1 | Invoke-Expression
$env:AIBOX_UNINSTALL_ALL = "1"; Invoke-RestMethod https://kebin.dev/cli/uninstall.ps1 | Invoke-Expression

Already have OpenCode?

The scripts add a provider named aibox and an MCP named searxng to ~/.config/opencode/opencode.json, backing up the old file first. API base https://ai.kebin.dev/v1, search MCP https://search.kebin.dev/mcp, both take the key as a bearer token.

Install

Needs Claude Code installed already (install it). Adds a claude-local command that runs it on ai.kebin.dev, with web search through search.kebin.dev.

curl -fsSL https://kebin.dev/cli/claude-install.sh | AIBOX_KEY=__AIBOX_KEY__ bash

Then

Open a project folder and start it. Plain claude keeps using Anthropic as before.

cd my-project
claude-local

Uninstall

Removes claude-local and its settings and history. Claude Code itself and your normal claude stay installed.

curl -fsSL https://kebin.dev/cli/claude-uninstall.sh | bash

Install

PowerShell. Needs Claude Code installed already (install it). Adds a claude-local command that runs it on ai.kebin.dev, with web search through search.kebin.dev.

$env:AIBOX_KEY = "__AIBOX_KEY__"; Invoke-RestMethod https://kebin.dev/cli/claude-install.ps1 | Invoke-Expression

Then

Open a new terminal in a project folder and start it. Plain claude keeps using Anthropic as before.

cd my-project
claude-local

Uninstall

Removes claude-local and its settings and history. Claude Code itself and your normal claude stay installed.

Invoke-RestMethod https://kebin.dev/cli/claude-uninstall.ps1 | Invoke-Expression

How it works

claude-local starts Claude Code with ANTHROPIC_BASE_URL=https://ai.kebin.dev, the key as ANTHROPIC_AUTH_TOKEN and the model set to qwen3.8-27b. It keeps its own settings and history in ~/.claude-local, so it never touches your normal Claude Code login or chats.
