OpenCode CLI

Run the coding agent on your own machine, in your own project, using the models on ai.kebin.dev.

Linux / macOS

Installs OpenCode if needed, asks for the API key, writes the config.

curl -fsSL https://kebin.dev/cli/install.sh | bash

Windows (PowerShell)

Needs Node.js, Scoop or Chocolatey present to install OpenCode.

irm https://kebin.dev/cli/install.ps1 | iex

Then

Open a project folder and start it. Pick a model inside OpenCode with /models.

cd my-project
opencode

Already have OpenCode?

The scripts only add a provider named aibox to ~/.config/opencode/opencode.json, backing up the old file first. API base https://ai.kebin.dev/v1, key required.

Uninstall

Removes the kebin.dev profile and restores your previous OpenCode config. Add --all (Linux/macOS) or set $env:AIBOX_UNINSTALL_ALL = "1" (Windows) to remove OpenCode itself as well.

curl -fsSL https://kebin.dev/cli/uninstall.sh | bash
curl -fsSL https://kebin.dev/cli/uninstall.sh | bash -s -- --all
irm https://kebin.dev/cli/uninstall.ps1 | iex
$env:AIBOX_UNINSTALL_ALL = "1"; irm https://kebin.dev/cli/uninstall.ps1 | iex
