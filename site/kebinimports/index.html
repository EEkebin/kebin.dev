What it does

Essentials

Avatar Essentials and World Essentials install your whole starter set in one click. Pick what goes in it with Customize Essentials.

Project Doctor

Finds what's wrong and offers a fix. Pink materials? It tells you they use lilToon and installs it. Missing scripts? It names the tool they came from.

Ask kebinAI

An AI that works inside your project: materials, shaders, PhysBones, installs and fixes. It asks before changing anything, and every change can be undone.

Real installs

Tools come from their official VPM listings, verified and added to your manifest, so the Creator Companion can keep updating them.

Quick Fixes

Fix Materials, Remove Missing Scripts, Fix Scripting Define Symbols, and a panic button that resets everything.

Load AssetBundle

Right-click a .vrca, .vrcw or .vrcp file to preview what's inside, without saving anything into the project.

Install

Pick one. All three put kebinImports in Packages/, not Assets/, and give you the same kebinImports menu in Unity.

VRChat Creator Companion / ALCOM recommended
  1. Click Add to VCC / ALCOM above. Or open Settings › Packages › Add Repository and paste this link:
    https://eekebin.github.io/kebinImports/index.json
  2. Open your project's Manage Project page, find kebinImports and click +.
  3. Open the project in Unity. The kebinImports menu is in the menu bar, and updates show up in the Creator Companion.
Unity Package Manager
  1. Download dev.kebin.kebinimports-<version>.tgz from the latest release.
  2. In Unity open Window › Package Manager, click + and choose Add package from tarball…
  3. Pick the .tgz file.
.unitypackage
  1. Download kebinImports.unitypackage.
  2. Drag it into Unity's Project window, or double-click it with the project open.
  3. Click Import. If an old copy is still in Assets/kebinImports, the Project Doctor offers to remove it.
